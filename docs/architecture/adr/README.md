# Architecture Decision Records

Короткие записи о решениях, которые трудно отменить. Формат: контекст →
решение → альтернативы → последствия. Новая оптимизация или смена технологии
обязательно получает ADR (§51 ТЗ: почему выбран алгоритм, какова сложность,
где масштабируется плохо, какое ускорение ожидается, как проверить).
