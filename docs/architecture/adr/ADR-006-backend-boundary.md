# ADR-006. Граница вычислительного backend'а — плотная линейная алгебра

**Статус:** принято · **Дата:** 2026-08-26

## Контекст
Нужно ускорять расчёты на CPU и GPU, не переписывая физику для каждого
устройства.

## Решение
`ComputeBackend` отвечает за `eigensolve_symmetric` и `gemm` (плюс будущие
факторизации). Рекурсии интегралов, XC-ядра и алгоритмы SCF живут выше и от
устройства не зависят.

## Альтернативы
- **Переносить каждый метод на GPU отдельно** — N реализаций одной физики и
  неизбежные расхождения между ними;
- **Полностью GPU-ядро** — недостижимо на старте и не нужно для малых систем.

## Последствия
- Диагонализация и умножения — 60–80 % времени SCF, поэтому выигрыш реален;
- Интегральные рекурсии остаются на CPU на первых этапах — это осознанный
  компромисс, измеряемый бенчмарком;
- Добавление нового устройства = реализация нескольких методов.
