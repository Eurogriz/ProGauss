# ADR-007. В коде только ключи локализации

**Статус:** принято · **Дата:** 2026-08-26

## Контекст
Русский интерфейс — обязательное требование (§3), английский — тоже.
Локализация, добавленная после разработки, почти всегда заканчивается
жёстко зашитыми строками в коде.

## Решение
Ни одного UI-текста в коде — только ключи каталога. Каталог общий для GUI,
CLI, REST-ошибок и отчётов. Паритет ru/en и совпадение плейсхолдеров
проверяются тестами, поэтому пропущенный перевод не доживает до релиза.
Подстановка — только именованными параметрами.

## Альтернативы
- **Строки в коде + автоматическое извлечение** — порядок слов и падежи
  ломаются при переводе;
- **Перевод на стороне клиента** — сообщения об ошибках приходят с сервера,
  клиент их не знает.

## Последствия
- Новый UI-текст требует записи в оба каталога (это и есть контроль качества);
- Каталог отдаётся через `GET /api/v1/i18n/{locale}`;
- Отсутствующий ключ — ошибка разработчика (`MissingTranslationKeyError`),
  а не пустая строка в интерфейсе.
