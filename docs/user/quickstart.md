# Мой первый расчёт за 5 минут

Это руководство написано для человека, который никогда не писал input-файлы
квантовохимических пакетов. Никакой специальной терминологии не требуется:
каждый термин объясняется там, где встречается.

> **Честное предупреждение о текущем состоянии.** На этом коммите реализован
> интерфейс платформы: создание структуры, подбор параметров, очередь заданий,
> журнал. **Расчётное ядро ещё не подключено**, поэтому расчёт не выполнится —
> система скажет об этом прямо и предложит варианты. Проверить, что доступно,
> можно командой `quantumlab capabilities`.

## 1. Установка

```bash
git clone <репозиторий> && cd ProGauss
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
quantumlab version
```

Ожидаемый вывод:

```
QuantumLab 0.1.0, контракт API v1
```

## 2. Возьмём молекулу

Если файла нет — подойдёт вода из тестовых данных (`tests/fixtures/water.xyz`).
Свою структуру сохраните в формате XYZ:

```
3
water
O     0.0000000000     0.0000000000     0.0000000000
H     0.7571689334     0.5865799573     0.0000000000
H    -0.7571689334     0.5865799573     0.0000000000
```

## 3. Проверим структуру

```bash
quantumlab molecule inspect tests/fixtures/water.xyz
```

```
Структура: water
  Брутто-формула: H2O
  Атомов: 3
  Электронов: 10
  Заряд: 0, мультиплетность: 1
  Проверка валентности: нарушений не найдено
  Подозрительные контакты: 0
```

**Что здесь важно:**

- **Электронов: 10** — считается автоматически как сумма атомных номеров минус
  заряд. Это число определяет, какие мультиплетности вообще возможны.
- **Мультиплетность: 1 (синглет)** — число, связанное с суммарным спином
  электронов. Для обычных молекул с чётным числом электронов это почти всегда 1.
  Если выбрать невозможное значение, система не промолчит, а предложит
  допустимые: например, для 10 электронов это 1, 3, 5, 7, 9.
- **Проверка валентности** — у каждого атома столько связей, сколько должно
  быть. Нарушение обычно означает ошибку при рисовании или импорте.
- **Подозрительные контакты** — атомы, оказавшиеся неестественно близко.

## 4. Посмотрим, что именно будет считаться

Вместо того чтобы подбирать параметры, выберите уровень точности — остальное
система сделает сама и объяснит:

```bash
quantumlab plan tests/fixtures/water.xyz --task optimize --profile high-accuracy
```

```
Конфигурация расчёта
  Оптимизация геометрии
  Потому что выбран профиль «Высокая точность»
  Выбран функционал pbe0
  Выбран базисный набор def2-tzvp
  Дисперсионная поправка: d3bj
  Квадратурная сетка: ultrafine
  Порог сходимости SCF: 1e-09
  Порог отсечки интегралов: 1e-11
  Число потоков: 1
  Память на расчёт: 1024 МБ — оценка по 30 базисным функциям
  Вычислительное устройство: auto — доступно GPU: 0
```

Уровни точности:

| Профиль | Что это | Когда выбирать |
|---|---|---|
| **Быстрый скрининг** (`--profile screening`) | PBE/def2-SVP | Оценить много структур быстро |
| **Стандартный** (`--profile standard`) | PBE0/def2-SVP | Обычная работа |
| **Высокая точность** (`--profile high-accuracy`) | PBE0/def2-TZVP | Значения для публикации |
| **Исследовательский** (`--profile research`) | ωB97X-D/def2-TZVP | Максимальный контроль |

Типы задач: `energy` (энергия), `optimize` (геометрия), `freq` (частоты и
термодинамика), `ts` (переходное состояние), `scan` (сканирование координаты),
`properties` (свойства).

## 5. Запустим расчёт

```bash
quantumlab run tests/fixtures/water.xyz --task optimize --profile standard
```

```
Задание создано: 2ea8fcc2-7e04-4b28-9ad0-d0a7fa9e5416 (water-optimization)
Задание поставлено в очередь: 2ea8fcc2-7e04-4b28-9ad0-d0a7fa9e5416
Расчётное ядро пока не подключено: задание сохранено в статусе «В очереди»
и будет выполнено, когда ядро станет доступно.
Метод пока недоступен
Метод dft заявлен в архитектуре, но его реализация ещё не прошла научную
верификацию, поэтому он отключён.
```

Задание создано и поставлено в очередь, а выполнить его нельзя — и система
говорит это прямо, вместо того чтобы показать выдуманные числа.

## 6. Поработаем с очередью

```bash
quantumlab job list
quantumlab job status <id>
quantumlab job logs   <id>
quantumlab job cancel <id>
quantumlab job retry  <id>
```

```
ID                                    СТАТУС              ПОПЫТКА  ИМЯ
2ea8fcc2-7e04-4b28-9ad0-d0a7fa9e5416   В очереди             0     water-optimization
```

Журнал показывает историю состояний — кто и когда перевёл задание:

```

  2026-08-26T19:26:10Z  Остановлен → В очереди  (cli)
```

## 7. Что дальше

| Хочу… | Команда |
|---|---|
| Узнать, что реально реализовано | `quantumlab capabilities` |
| Посмотреть только базисы | `quantumlab capabilities --kind basis` |
| Задать метод вручную (экспертный режим) | `quantumlab run mol.xyz --method dft --functional pbe0 --basis def2-tzvp` |
| С дисперсионной поправкой D3 (экспертный режим) | `quantumlab run mol.xyz --method dft --functional pbe0 --basis def2-svp --dispersion d3bj` |
| Переключить язык вывода | `quantumlab --lang en …` |
| Хранить задания в другом каталоге | `quantumlab --data-dir /путь …` |

## Если что-то пошло не так

Сообщения об ошибках состоят из трёх частей: **что произошло**, **что система
попробовала**, **что можно сделать**. Например, при невозможном сочетании
заряда и мультиплетности:

```
Заряд и мультиплетность несовместимы
При заряде 0 в системе 10 электронов, поэтому мультиплетность 2 невозможна.
Допустимые значения: 1, 3, 5, 7, 9. Обычно для молекул с чётным числом
электронов это синглет (1) или триплет (3).
```
